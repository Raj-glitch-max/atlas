# Maintainers

This file lists the maintainers of the Atlas project. Maintainers are
responsible for reviewing and merging contributions, cutting releases,
and stewarding the project's technical direction and governance (see
[`GOVERNANCE.md`](GOVERNANCE.md)).

## Bus factor — stated honestly

Atlas currently has **one maintainer**. This is a known risk, tracked as an
incubation blocker in [`RISK_REGISTER.md`](RISK_REGISTER.md) and in the review
stack (`agents/review-team/output/`). The path to a second maintainer:

1. A contributor lands three non-trivial, independently reviewed changes.
2. They are proposed as a maintainer per the process in [`GOVERNANCE.md`](GOVERNANCE.md).
3. `MAINTAINERS.md` and [`.github/CODEOWNERS`](.github/CODEOWNERS) are updated in
   the same change that adds them.

Declaring this file with a single name is deliberate: it makes the succession
shape explicit rather than implicit, which is the point of the file existing.
